02 / Platform Design

High-Level System Architecture

Stateful orchestration, asynchronous workers, and resilient multi-provider LLM pipelines.

🏗

  • Frontend Dashboard: Next.js 16 App Router with Tailwind CSS, Zustand stores, and React Query streaming.

  • Central Prompt Registry: `PromptRegistry` manages versioned templates (`planner_v1`, `repo_analyzer_v1`) with runtime variable validation. Zero hardcoded prompts.

05 / Code Intelligence

Repository Analysis Engine

Deterministic code parsing, static security wrappers, and AST dependency extraction.

🌲
AST & Structural Target Discovery
  • Tree-Sitter AST Service: Identifies target parse files and structural nodes across multi-language codebases.
  • Python Symbol Graph: `ImportGraphService` extracts top-level class definitions, function signatures, and import relationships.
  • Git History Service: `GitHistoryService` uses GitPython to parse recent commits, author metadata, and change density.
  • Redis SHA Caching: SHA-256 keyed cache stores repository summaries to avoid expensive re-indexing.
🔍
Static Analysis Tool Suite

Subprocess-isolated static tools wrapped with zero shell interpolation (`shell=False`) for maximum security execution:

Ruff: Ultra-fast Python code linting & style enforcement.
Bandit: AST security vulnerability scanner for Python.
Semgrep: Lightweight static analysis for multi-language rules.
Radon: Cyclomatic complexity & maintainability metrics.
06 / Cyber Defense

Enterprise Security & Hardening

Multi-layered defense with automatic secret sanitization, zero-trust RBAC, and audit trails.

🛡
Secret Sanitizer & Redaction Engine

Automatic regex-based redactor scanning all logs, exceptions, and outbound AI payloads before transmission:

# Redacts API keys, tokens, & secrets instantly: Input: "Bearer sk-proj-98712398127391823" Output: "Bearer [REDACTED_API_KEY]" Matches: OpenAI (sk-...), Groq (gsk_...), GitHub (ghp_...), JWTs, RSA Keys
🔐
Access Control & Audit Logging
  • Role Hierarchy: Granular RBAC enforcing `OWNER` > `ADMIN` > `MEMBER` > `VIEWER` access scopes.
  • Strict Webhooks: Webhook request payload verification via HMAC-SHA256 signature enforcement.
  • Append-Only Audit Log: In-memory `AuditLogger` capturing every state mutation with sanitized metadata.
  • HTTP Hardening: Helmet-equivalent headers (`HSTS`, `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`).
